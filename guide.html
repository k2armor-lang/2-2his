시대를 고르고, 자료를 담고, 나만의 설명을 붙입니다. 완성한 전시는 선생님께 제출하기 버튼으로 제출하세요.

전시실 1곳·선택 이유 1편·자료 3점·제출 1회

01 / 기획부터 제출까지

이 순서로 따라오세요

  1. 01

    학번과 이름을 입력하고 입장하기

    처음 열리는 화면에서 학번·이름을 입력한 뒤 기획 시작하기를 누르세요. 입장하면 전시관 로비가 열립니다.

    잘못 입력했다면 맨 위 학번·이름 수정으로 고치세요. 로그아웃은 학번·이름과 작성한 내용을 모두 지우고 처음부터 다시 시작하는 기능입니다.

  2. 02

    전시실 하나를 선택하기

    제1전시실(1910~1945년), 제2전시실(1945~1960년), 제3전시실(1960년~현재) 중 한 곳을 누르세요. 확인 팝업에서 전시실을 살펴보고 선택하기를 누르면 입장합니다. 다른 곳을 둘러보려면 다시 고르기를 누르세요.

    선택한 카드에는 ✓ 선택한 전시실 표시가 나타나고 내 전시실 열기가 표시됩니다. 나머지 두 곳은 선택할 수 없습니다.

    선택을 바꾸려면 로비의 다른 전시실로 바꾸기를 누르세요. 변경을 확인하면 기존 선택 이유와 자료가 모두 지워지니 신중하게 고르세요.

  3. 03

    선택 이유와 자료 세 점 채우기

    맨 위 이 전시실을 선택한 이유에 왜 이 시대를 골랐는지 적으세요. 자료 카드 세 장이 처음부터 놓여 있으니 모두 채우세요. 위쪽 전시 자료 0 / 3점 완성 표시로 진행 상황을 확인할 수 있습니다.

    각 카드의 액자 안쪽을 눌러 사진을 넣고, 자료 설명과 역사적 배경과 의미를 작성하세요. 유물·문화재나 역사적 사건 사진을 사용할 수 있습니다. 글이 길어지면 입력칸도 늘어납니다.

    EXHIBIT 머리글을 누르면 카드를 접거나 펼 수 있습니다. 카드 오른쪽 위 ×로 삭제하면 그 카드의 사진과 글도 함께 지워집니다.

  4. 04

    자동 저장을 확인하며 이어 쓰기

    작성 내용은 현재 기기의 브라우저에 자동 저장됩니다. 저장됨 ✓ 표시를 확인하고, 처음부터 끝까지 같은 기기·같은 브라우저에서 작업하세요.

    다른 기기나 브라우저에는 내용이 이어지지 않습니다. 일반 창을 사용하고, 작성 중에는 사이트 데이터를 지우지 마세요. 저장 오류가 뜨면 사진을 지우거나 용량이 작은 사진으로 바꿔 주세요.

  5. 05

    선생님께 제출하기

    로비 아래쪽 제출하기 칸에서 선생님께 제출하기 버튼을 누르면 제출됩니다. 파일을 따로 저장하거나 보낼 필요가 없고, 로그인도 필요 없습니다.

    “정말 선생님께 제출할까요?” 창이 뜨면 학번·이름과 전시실을 확인하고 확인을 누르세요. 빈칸이 있거나 이미 제출했다면 같은 창에 함께 알려 줍니다.

    제출하는 데 길게는 30초쯤 걸립니다. 화면을 닫지 말고 기다렸다가 제출 완료 문구를 확인하세요. 고친 뒤 다시 제출하면 마지막 제출본만 남습니다.

    제출이 계속 실패하면 화면의 오류 문구를 선생님께 보여 주세요. 제출한 내용은 기기에도 보관되어, 같은 기기에서 기기에 보관된 제출본 다시 보내기로 다시 보낼 수 있습니다.

제출 전, 한 번 더 확인

  • 학번·이름이 정확한가요?
  • 선택 이유와 자료 세 점의 사진·설명을 모두 채웠나요?
  • 선생님께 제출하기를 누르고 제출 완료까지 확인했나요?

내 작업을 지키려면

로그아웃과 다른 전시실로 바꾸기를 확인하면 작성한 내용이 지워집니다. 사이트 데이터 삭제와 비공개 브라우징 종료로도 내용을 잃을 수 있습니다.

완성하면 선생님께 제출하기로 꼭 제출하세요. 제출이 막히면 화면의 안내를 확인하고 선생님께 도움을 요청하세요.
